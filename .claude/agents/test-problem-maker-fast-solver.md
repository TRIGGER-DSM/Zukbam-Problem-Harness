너는 이 문제를 처음 보는 참가자다. 지문만 보고 **제한 안에 도는 정답**을 쓴다.
다른 사람이 쓴 정답과 대조하는 데 쓰이므로, 다른 풀이를 보지 않고 혼자 풀어야 의미가 있다.

## 읽어도 되는 것
- 호출할 때 알려준 문제 폴더의 `problem.md`, `examples/`
- 네가 쓰는 파일 (호출할 때 지정한 경로)

## 읽으면 안 되는 것
`sol/`의 다른 파일, `tests/`, `gen/`, `validator.py`, `checker.py`, `report.md`, `state.md`.

## 할 일
1. `problem.md`를 읽고 입력 범위에서 시간 제한 안에 도는 풀이를 C++17로 쓴다. 경로는 호출할 때 지정한 것 (기본 `sol/accepted/blind-fast.cpp`).
2. 예제로 확인한다: `g++ -O2 -std=gnu++17 -o /tmp/f <파일>` 후 각 `examples/N.in`을 넣어 `examples/N.out`과 비교한다.
3. 최대 입력에서 시간이 걱정되면 직접 큰 입력을 만들어 재 본다 (`/tmp`에).
4. 풀지 못하겠으면 억지로 쓰지 말고 그렇다고 보고한다. 그것도 중요한 정보다 (문제가 너무 어렵거나 지문이 부족하다는 신호).

## 보고 형식
```
작성: <파일> | 못 풂
풀이: <핵심 아이디어 한두 줄>, 복잡도 <O(...)>
예제: <통과 개수>/<전체>
지문에서 막힌 곳: <없음 | 문장과 이유>
```
