# 골드 문제 특징

> solved.ac 메타데이터(2026-10-13, 골드 7,758문제)와 대표 문제 30개 분석. 대표 문제는 인터넷 검색으로 확인하고, 찾지 못한 것은 기억으로 채웠다(출처 칸). 지문 원문은 담지 않는다.

## 요약: 골드로 만들 때

- **풀이**: 표준 기법에 관찰 하나, 또는 기법 두 개의 조합. 문제당 태그 2.9~3.4개, 그래프·DP·수학이 각각 20~25%. 대표 문제 30개 중 23개에 "비튼 점"이 있다.
- **세부 티어**
  - 골드 5: 기본 기법의 정석 (0/1 배낭, 멀티 소스 BFS, 활동 선택 그리디, 투 포인터, 조합 백트래킹). 관찰 1~2개.
  - 골드 3: 기법을 한 번 확장 (BFS 상태에 "벽을 부쉈는지" 추가, BFS 두 개를 시간 순으로 비교, 메모이제이션 경로 수, 함수형 그래프 사이클, 스택 그리디, 체 + 투 포인터). 관찰 2개.
  - 골드 1: 기법 둘 이상 조합이나 상태 압축 (BFS + 비트마스크 TSP, 열쇠 비트를 상태로 둔 BFS, 라벨링 + MST, 세그먼트 트리 기본, 구간 체). 관찰 2~3개.
- **자주 쓰는 비틀기**: 상태에 차원 하나 추가(벽 부숨, 열쇠, 층), 시작점 여러 개, 두 과정의 시간 비교, 기존 문제의 차원 확장(2차원→3차원), 기법 둘 이어 붙이기.
- **제약**: N이 10⁵ 안팎이면 O(N log N), 격자는 10³×10³까지. 상태를 키우는 문제는 상태 수 × 전이가 10⁷~10⁸ 안에 들게 작은 축을 둔다 (열쇠 6종, 비트마스크 N ≤ 16).
- **시뮬레이션 골드**: 규칙이 많은 구현(구슬 탈출, 2048, 아기 상어)도 골드다. 규칙 수와 경우 처리가 난이도를 만든다.
- **지문**: 이야기형이 대부분이다. 규칙이 길고, 우선순위(위·왼쪽 먼저 등)와 동률 처리를 반드시 명시한다.
- **흔한 실수**: 방문 처리를 상태 전체가 아니라 칸에만 하는 것, 동시에 퍼지는 과정의 순서, 정렬 기준의 동률, 오버플로.
- **만들 때**: "알려진 기법 하나 + 학생이 찾아야 할 비틀기 하나"가 기본 틀이다. 비틀기가 없으면 골드 5, 상태 확장이나 기법 결합이 있으면 골드 3~1.

## 문제별 특징

### 1194 달이 차오른다, 가자. (골드 1) — 그래프 이론, 그래프 탐색, 너비 우선 탐색, 비트마스킹, 격자 그래프
- 무엇을 구하나: 미로에서 열쇠(a~f)를 모아 같은 종류 문(A~F)을 열며 출구까지 가는 최단 거리를 구한다.
- 지문 유형: 이야기형(미로, 열쇠와 문)
- 입력: N×M 격자 문자열
- 제약: 열쇠 6종, 격자 크기는 50 이하로 기억함(확실하지 않음)
- 의도 풀이: 방문 상태를 (y, x, 열쇠 비트마스크)로 하는 BFS
- 복잡도: O(NM·2^6)
- 비틀기: 기본 BFS에 열쇠 비트 상태 추가
- 막히는 쉬운 풀이: 열쇠 조합을 DFS로 전부 탐색하면 시간 초과
- 지문 특징: 격자 문자 종류를 나열하는 중간 길이 지문
- 이 티어인 이유: BFS 자체는 기본이나 상태 확장을 떠올려야 해서 골드 1
- 핵심 관찰: 보유 열쇠 집합을 상태에 포함한다; 열쇠는 같은 종류 문을 여러 번 열 수 있다
- 흔한 실수: 방문 배열에 열쇠 차원을 빼먹음; 출구 도달 조건; 열쇠를 줍는 순간 마스크 갱신
- 출처: 웹

### 4991 로봇 청소기 (골드 1) — 그래프 이론, 브루트포스 알고리즘, 그래프 탐색, 너비 우선 탐색, 비트마스킹
- 무엇을 구하나: 로봇이 모든 더러운 칸을 청소하는 최소 이동 횟수를 구한다. 불가능하면 -1.
- 지문 유형: 이야기형(로봇 청소기)
- 입력: 여러 테스트: w, h와 격자, 0 0으로 종료
- 제약: w,h ≤ 20, 더러운 칸 ≤ 10
- 의도 풀이: BFS로 점 쌍 거리를 구하고 순열 또는 비트마스크 DP로 TSP
- 복잡도: O(K·BFS + K!) 또는 O(K^2 2^K)
- 비틀기: BFS와 TSP를 결합
- 막히는 쉬운 풀이: 순열마다 BFS는 시간 초과
- 지문 특징: 설명은 짧고 여러 테스트케이스
- 이 티어인 이유: BFS와 TSP를 결합해야 해 골드 1
- 핵심 관찰: 점 간 BFS 거리를 미리 계산; 방문 순서 순열/TSP
- 흔한 실수: 도달 불가 시 -1; 종료 입력 0 0; 가구 칸 처리
- 출처: 웹

### 2042 구간 합 구하기 (골드 1) — 세그먼트 트리, 자료 구조
- 무엇을 구하나: 수열에서 값 변경과 구간 합 질의를 모두 처리한다.
- 지문 유형: 추상형
- 입력: N, M(변경 수), K(질의 수), 수열, 쿼리 M+K개
- 제약: N ≤ 1000000, M,K ≤ 10000, 합은 long 범위
- 의도 풀이: 세그먼트 트리 또는 펜윅 트리의 점 갱신 / 구간 합
- 복잡도: O((M+K) log N)
- 비틀기: 없음(세그먼트 트리 기본 문제)
- 막히는 쉬운 풀이: 누적합 재계산은 갱신마다 O(N)
- 지문 특징: 짧은 지문, 예제 1개
- 이 티어인 이유: 세그먼트 트리를 처음 구현해야 해 골드 1로 분류
- 핵심 관찰: 갱신이 있으면 누적합을 쓸 수 없음; 트리로 로그 시간 갱신/질의
- 흔한 실수: 합이 int 오버플로; 쿼리 종류 구분; 1-index

- 의도 풀이: 치킨집 M개 조합을 모두 보고 맨해튼 거리 합 계산
- 복잡도: O(C(13,M) · 집 수 · M)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 이야기 + 용어 정의가 긴 편
- 이 티어인 이유: 완전탐색 구현 위주, 관찰 거의 없음
- 핵심 관찰: 치킨집이 최대 13개라 조합 완전탐색 가능
- 흔한 실수: 정확히 M개 선택이 항상 최적(적게 남기면 불리); 맨해튼 거리; 집마다 가장 가까운 치킨집
- 출처: 웹

### 1759 암호 만들기 (골드 5) — 수학, 브루트포스 알고리즘, 조합론, 백트래킹
- 무엇을 구하나: C개의 알파벳에서 L개를 골라 모음 1개 이상, 자음 2개 이상이며 사전순인 암호를 모두 출력한다.
- 지문 유형: 이야기형, 암호 만들기
- 입력: L, C와 C개의 소문자
- 제약: 3 ≤ L ≤ C ≤ 15
- 시간 제한: 2초
- 의도 풀이: 문자를 정렬하고 조합을 백트래킹으로 생성하며 모음·자음 개수 검사
- 복잡도: O(2^C · C)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 이야기 + 조건 나열, 예제 1개
- 이 티어인 이유: 조합 생성 기본에 조건 검사만 추가
- 핵심 관찰: 정렬 후 인덱스 증가 방향으로만 고르면 사전순 보장
- 흔한 실수: 입력 문자 정렬 누락; 모음 판정 aeiou; 출력 순서
- 출처: 웹

### 2470 두 용액 (골드 5) — 정렬, 이분 탐색, 두 포인터
- 무엇을 구하나: 산성·알칼리 용액 중 두 개를 섞어 합이 0에 가장 가까운 쌍을 찾는다.
- 지문 유형: 이야기형(용액)
- 입력: N과 특성값 N개
- 제약: N ≤ 100000, 값 ±10^9
- 의도 풀이: 정렬 후 투 포인터 또는 이분 탐색
- 복잡도: O(N log N)
- 비틀기: 없음(기본 두 포인터)
- 막히는 쉬운 풀이: O(N^2) 쌍 탐색은 시간 초과
- 지문 특징: 짧음, 예제 2개
- 이 티어인 이유: 기본 투 포인터라 골드 5
- 핵심 관찰: 정렬하면 양 끝에서 투 포인터
- 흔한 실수: 합 오버플로(long); 오름차순 출력; 양수/음수만 있는 입력
- 출처: 웹
