# 다이아 문제 특징

> solved.ac 메타데이터(2026-10-13, 다이아 4,332문제)와 대표 문제 30개 분석. 대표 문제는 인터넷 검색으로 확인하고, 찾지 못한 것은 기억으로 채웠다(출처 칸). 지문 원문은 담지 않는다.

## 요약: 다이아로 만들 때

- **풀이**: 고급 기법의 조합과 관찰 둘 이상, 또는 DP 최적화·특수 자료구조. 문제당 태그 4.0~4.4개, 자료구조 약 30%, 세그먼트 트리·트리가 각각 15% 안팎. 대표 문제의 평균 관찰 수는 2.5개로 가장 많다.
- **세부 티어**
  - 다이아 5: 기법 둘의 결합 (좌표 압축 + 스위핑 + 최대 부분합 세그먼트 트리, 누적 합 + CHT, 삼분 탐색 + 회전하는 캘리퍼스, 뫼비우스 + 이분 탐색, 차분 + 세그먼트 트리 gcd, 오프라인 HLD).
  - 다이아 3: 기법을 낯선 구조로 옮기기 (트리 경로 위 CHT와 롤백, 슬로프 트릭, 스플레이 트리, 정수론 정리 응용, 병렬 이분 탐색).
  - 다이아 1: 고급 기법의 깊은 응용 (세그먼트 트리 비츠, 기울기 트릭 병합, 메모리 제한으로 강제한 히르쉬버그).
- **자주 쓰는 비틀기**: 익숙한 문제(히스토그램, 부분합, LCS)에 제약 하나를 더해 고급 기법이 필요하게 만들기 (메모리 4MB, 쿼리 추가, 온라인 → 오프라인).
- **제약**: N, Q ≤ 10⁵~10⁶. 의도 풀이만 통과하도록 log 하나 차이까지 고려한다. Python 정답이 시간 안에 못 들어올 수 있으니 시간 제한을 넉넉히 두거나 그 사실을 보고한다.
- **자료 한계**: 이 티어 대표 문제는 인터넷에 풀이가 적어 30개 중 10개를 확인하지 못했다. 아래 표에서 출처가 "기억"인 항목은 참고만 한다.
- **검증 주의**: brute-force는 작은 입력만 보므로, 두 번째 정답은 주 정답과 다른 방법으로 쓰게 한다. 난이도 신호(Haiku 풀이)가 "쉬움"이면 비틀기를 하나 더 넣는다.
- **만들 때**: 플래티넘 기법 하나에 관찰 둘 이상을 쌓는다. 유명 문제(히스토그램, 금광, 수열과 쿼리)의 이야기만 바꾸지 않도록, 구하는 것 자체를 바꾼다.

## 문제별 특징

### 17474 수열과 쿼리 26 (다이아 1) — 자료 구조, 세그먼트 트리, 느리게 갱신되는 세그먼트 트리, 세그먼트 트리 비츠
- 무엇을 구하나: 수열에 구간 chmin 갱신과 구간 최댓값/합 질의가 섞여 들어온다. (기억 기준, 세부 연산은 불확실)
- 지문 유형: 추상형
- 입력: 수열 하나와 쿼리 Q개
- 제약: N, Q 최대 약 10^5 규모(정확치 모름)
- 의도 풀이: 세그먼트 트리 비츠로 최댓값·두 번째 최댓값·최댓값 개수를 유지
- 복잡도: O((N+Q) log N) 상각 (또는 log^2)
- 비틀기: 세그먼트 트리 비츠 기본형
- 막히는 쉬운 풀이: 구간 순회로 갱신하는 O(NQ) 풀이
- 지문 특징: 짧은 연산 정의형(기억)
- 이 티어인 이유: 비츠라는 비직관적 상각 분석 기법 필요
- 핵심 관찰: 최댓값만 바꾸는 갱신이면 최대·차대 최댓값만 보면 된다; 차대값보다 크고 최댓값 이하의 x면 태그만 달 수 있다
- 흔한 실수: 합이 int 범위를 넘음; 차대값 처리 경계(같을 때)
- 출처: 기억

### 18438 LCS 5 (다이아 1) — 다이나믹 프로그래밍, 분할 정복, 역추적, 최장 공통 부분 수열 문제, 히르쉬버그
- 무엇을 구하나: 두 문자열의 LCS 길이와 그 문자열을 매우 작은 메모리로 복원한다.
- 지문 유형: 추상형
- 입력: 문자열 두 개
- 제약: 길이 ≤ 약 7000, 메모리 4MB
- 의도 풀이: 히르쉬버그 알고리즘(분할 정복 + 선형 공간 LCS)
- 복잡도: O(NM) 시간, O(N) 공간
- 비틀기: LCS 복원을 메모리 제한으로 막음
- 막히는 쉬운 풀이: 2차원 DP 표 역추적
- 지문 특징: 짧음, 메모리 제한이 핵심
- 이 티어인 이유: 히르쉬버그 개념 모르면 불가
- 핵심 관찰: O(NM) 표를 못 둔다; 두 행만 쓰면 역추적 불가; 중간 행에서 분할점을 찾아 재귀
- 흔한 실수: 재귀 중 메모리; 역순 문자열 DP
- 출처: 웹

- 입력: 모름
- 제약: 모름
- 의도 풀이: 모름
- 비틀기: 모름

- 지문 특징: 모름

### 12736 Fireworks (다이아 1) — 다이나믹 프로그래밍, 자료 구조, 트리, 트리에서의 다이나믹 프로그래밍, 우선순위 큐, 작은 집합에서 큰 집합으로 합치는 테크닉, 함수 개형을 이용한 최적화
- 무엇을 구하나: 트리의 간선 길이를 바꿔 모든 말단까지 거리를 같게 만들 때 총 변경량을 최소화한다.
- 지문 유형: 이야기형(불꽃놀이)
- 입력: 트리 간선과 가중치
- 제약: 노드 최대 약 3·10^5
- 의도 풀이: 기울기 트릭: 각 노드에서 함수의 꺾이는 점을 힙에 저장해 병합
- 복잡도: O(N log N)
- 비틀기: 기울기 트릭 고전
- 막히는 쉬운 풀이: 트리 DP O(N * 값)
- 지문 특징: 이야기 길이 중간
- 이 티어인 이유: 기울기 트릭 발상이 어려움
- 핵심 관찰: 각 서브트리 비용은 볼록 구간선형 함수; 기울기 변화점을 우선순위 큐로 합침; 루트에서 기울기 0 되는 지점 계산
- 흔한 실수: long long; 힙 병합 방식

- 출처: 기억

### 4008 특공대 (다이아 5) — 다이나믹 프로그래밍, 누적 합, 볼록 껍질을 이용한 최적화
- 무엇을 구하나: 병사 열을 연속 구간으로 나눠 구간 합 x에 대한 2차식 a x^2+bx+c의 합을 최대화한다.
- 지문 유형: 이야기형(군대 특공대)
- 입력: 병사 수 N, 계수 a,b,c, 전투력 수열
- 제약: N ≤ 10^6, a<0
- 의도 풀이: 누적 합 + 볼록 껍질 트릭(CHT)으로 dp 최적화
- 복잡도: O(N)
- 비틀기: CHT 기본형
- 막히는 쉬운 풀이: O(N^2) DP
- 지문 특징: 짧고 식이 명시됨
- 이 티어인 이유: DP 식 전개와 CHT 정립 필요
- 핵심 관찰: dp[i]=max dp[j]+a(S_i-S_j)^2+b(S_i-S_j)+c; 식을 전개하면 직선 최댓값 질의 형태; 기울기 단조라 덱으로 O(N)
- 흔한 실수: long long 필요; a의 부호 따라 최대/최소 방향
- 출처: 기억

### 13310 먼 별 (다이아 5) — 기하학, 볼록 껍질, 삼분 탐색, 회전하는 캘리퍼스
- 무엇을 구하나: 별들이 등속 직선 이동할 때 별 집합의 지름이 최소가 되는 시각을 구한다.
- 지문 유형: 이야기형(별)
- 입력: 별 N개의 위치와 속도
- 제약: N ≤ 약 5·10^4
- 의도 풀이: 시간에 대한 지름 함수가 볼록이라 삼분 탐색, 각 시각마다 볼록 껍질+캘리퍼스로 지름
- 복잡도: O(N log N * 탐색횟수)
- 비틀기: 삼분 탐색과 기하 결합
- 막히는 쉬운 풀이: 모든 시각 탐색
- 지문 특징: 짧음
- 이 티어인 이유: 기하 알고리즘 결합
- 핵심 관찰: 시간에 대해 두 점 거리 함수 볼록 → 최대도 볼록; 정수 시각 삼분 탐색; 매 시각 지름 계산
- 흔한 실수: 정수 시각만 허용 여부; 동점 시 가장 이른 시각; 거리 제곱 오버플로
- 출처: 기억

### 1031 스타 대결 (다이아 5) — 그래프 이론, 최대 유량
- 무엇을 구하나: 두 팀의 선수별 경기 횟수가 주어질 때 각 쌍이 최대 한 번 대결하는 경기표 중 사전순 최소를 구한다.
- 지문 유형: 이야기형(스타크래프트)
- 입력: 팀 크기 N, M과 선수별 경기 수
- 제약: N, M ≤ 50
- 의도 풀이: 이분 그래프 유량 모델링 후 칸마다 1을 0으로 바꿔보며 유량 유지 확인
- 복잡도: O(NM * flow)
- 비틀기: 유량의 사전순 구성
- 막히는 쉬운 풀이: 모든 경우 탐색
- 지문 특징: 짧음
- 이 티어인 이유: 유량 모델링과 사전순 구성
- 핵심 관찰: 행합·열합 만족하는 0/1 행렬 = 유량; 사전순 최소는 앞칸부터 0 시도, 불가능하면 1
- 흔한 실수: 불가능 판정(-1); 합이 맞지 않음
- 출처: 기억

### 1557 제곱 ㄴㄴ (다이아 5) — 수학, 정수론, 이분 탐색, 포함 배제의 원리
- 무엇을 구하나: 어떤 1보다 큰 제곱수로도 나누어지지 않는 수 중 K번째 수를 구한다.
- 지문 유형: 추상형
- 입력: 정수 K 하나
- 제약: K ≤ 10^9 (답은 약 2·10^9 이내)
- 의도 풀이: 뫼비우스 함수로 X 이하 제곱ㄴㄴ수 개수를 세고 이분 탐색
- 복잡도: O(sqrt(X) + sqrt(X) log X)
- 비틀기: 포함 배제를 이분 탐색과 결합
- 막히는 쉬운 풀이: K번째까지 하나씩 제곱 판정하는 O(K sqrt K)
- 지문 특징: 한 줄 정의와 입력 하나, 예제 짧음
- 이 티어인 이유: 포함 배제를 뫼비우스로 일반화하고 이분 탐색과 엮음
- 핵심 관찰: X 이하 개수 = sum mu(d) * floor(X/d^2); 답의 상한을 약 2K로 잡고 이분 탐색; mu는 sqrt(상한)까지 체로 구함
- 흔한 실수: 이분 탐색 상한 부족; int 오버플로(2·10^9)
- 출처: 기억

### 12858 Range GCD (다이아 5) — 수학, 자료 구조, 정수론, 세그먼트 트리, 느리게 갱신되는 세그먼트 트리, 유클리드 호제법, 차분 배열 트릭
- 무엇을 구하나: 수열에서 구간에 값을 더하는 갱신과 구간 gcd 질의를 처리한다.
- 지문 유형: 추상형
- 입력: 수열과 쿼리 Q개
- 제약: N, Q 최대 약 5·10^5
- 의도 풀이: gcd(a_l, 차분 배열의 구간 gcd), 차분에 세그먼트 트리 + BIT로 a_l 복원
- 복잡도: O((N+Q) log N)
- 비틀기: 느리게 갱신 대신 차분으로 변환
- 막히는 쉬운 풀이: 구간 직접 갱신 O(NQ)
- 지문 특징: 짧음
- 이 티어인 이유: 차분 트릭 관찰이 핵심
- 핵심 관찰: gcd(a_l..a_r)=gcd(a_l, gcd(d_{l+1..r})); 구간 가산은 차분 두 점 갱신; a_l은 BIT로 계산
- 흔한 실수: gcd(0,x) 처리; 음수 차분은 절댓값; long long
- 출처: 기억

### 2927 남극 탐험 (다이아 5) — 자료 구조, 트리, 세그먼트 트리, 분리 집합, 오프라인 쿼리, Heavy-light 분할
- 무엇을 구하나: 섬들 사이에 다리를 놓는 중 두 섬 연결 여부, 펭귄 수 갱신, 경로 위 펭귄 합을 묻는다.
- 지문 유형: 이야기형(남극 펭귄)
- 입력: 섬 N, 쿼리 Q개 (bridge/penguins/excursion)
- 제약: N ≤ 3·10^4, Q ≤ 3·10^5 정도
- 의도 풀이: 오프라인으로 최종 숲 구성 후 HLD + 세그/BIT, DSU로 연결 확인
- 복잡도: O((N+Q) log^2 N)
- 비틀기: 동적 연결을 오프라인 HLD로 변환
- 막히는 쉬운 풀이: 온라인 LCT
- 지문 특징: 쿼리 3종 명세
- 이 티어인 이유: HLD와 오프라인 처리의 결합
- 핵심 관찰: 다리 연결은 시간순이므로 오프라인으로 최종 숲 먼저 구성; 연결 안 된 쿼리는 DSU로 판정; 연결 후엔 트리 경로 합
- 흔한 실수: 간선 추가 시점과 쿼리 시점; 같은 컴포넌트 판정
- 출처: 기억
