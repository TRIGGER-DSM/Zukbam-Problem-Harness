# 브론즈 문제 특징

> solved.ac 메타데이터(2026-10-13, 브론즈 3,267문제)와 대표 문제 32개 분석. 대표 문제는 인터넷 검색으로 확인하고, 찾지 못한 것은 기억으로 채웠다(출처 칸). 지문 원문은 담지 않는다.

## 요약: 브론즈로 만들 때

- **풀이**: 지문을 그대로 코드로 옮기면 풀린다. 문제당 태그 2.0~2.4개, 구현 63~77%, 수학·사칙연산이 대부분이다. 대표 문제 29개 중 "비튼 점"이 있는 것은 5개뿐이다.
- **세부 티어**
  - 브론즈 5~4: 입력 몇 개를 받아 사칙연산이나 조건 분기 한두 번 (A+B, 사분면 고르기, 세 수 중 가운데). 관찰 0개.
  - 브론즈 3~2: 반복문과 배열·문자열 처리, 단위 변환과 나머지 연산(알람 시계), 작은 시뮬레이션(공 넣기), 단순 순회(최소·최대). 관찰 0~1개.
  - 브론즈 1: 여러 단계를 이어 붙인 구현(빈도 배열 후 최댓값과 동률 처리, 평균을 넘는 비율), 작은 완전 탐색(일곱 난쟁이: 9명 중 2명 빼기), 간단한 점화식(부녀회장: 표 채우기, 피보나치). 관찰 1개, 많아야 2개.
- **DP는 브론즈에 드물다**: 브론즈 DP는 2~1에 몇 개뿐이고, 형태는 "점화식을 지문이 거의 알려 주는 표 채우기"다 (부녀회장 k, n ≤ 14, 피보나치 n ≤ 45).
- **제약**: 값과 N이 작다 (대부분 ≤ 1,000). 시간 제한으로 쉬운 풀이를 막지 않는다. 예외는 재귀 피보나치처럼 지수 시간 풀이 정도다.
- **지문**: 짧다. 이야기형과 추상형이 반반이고, 이야기도 한두 문장의 소재 수준이다. 예제 1~2개.
- **흔한 실수 (TC에 넣을 것)**: 경계(0, 최댓값, 동률), 출력 형식(소수 자릿수, 대소문자), 나머지 연산의 음수·자정 넘김.
- **만들 때**: 기법 이름이 필요 없어야 한다. 관찰이 하나라도 숨어 있으면 브론즈 1, 없으면 브론즈 3 이하. 구현 단계가 3개를 넘거나 정렬·완전 탐색이 핵심이면 실버로 올라간다.

## 문제별 특징

### 10219 Meats On The Grill (브론즈 1) — 구현, 애드 혹, 해 구성하기
- 무엇을 구하나: 격자로 주어진 석쇠의 고기를 좌우로 뒤집은 모양을 출력하는 문제로 기억한다.
- 지문 유형: 이야기형 - 고기 굽기
- 입력: 테스트케이스 T, 각 케이스는 H×W 격자
- 제약: 모름
- 의도 풀이: 각 행을 뒤집어 출력
- 복잡도: O(HW)
- 비틀기: 모름
- 막히는 쉬운 풀이: 없음
- 지문 특징: 모름
- 이 티어인 이유: 모름
- 흔한 실수: 행 뒤집기와 열 뒤집기 혼동
- 출처: 기억

### 4344 평균은 넘겠지 (브론즈 1) — 수학, 사칙연산
- 무엇을 구하나: 여러 테스트 케이스에서 학생 점수들의 평균을 넘는 학생의 비율을 퍼센트로, 소수 셋째 자리까지 출력한다.
- 지문 유형: 이야기형(대학생 성적)
- 입력: 테스트 케이스 수 C, 각 줄에 학생 수 N과 N개 점수
- 제약: N ≤ 1000, 점수는 0~100
- 시간 제한: 1초
- 의도 풀이: 합으로 평균 계산 후 평균 초과 인원 비율 계산
- 복잡도: O(합계 N)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 짧은 이야기, 예제 1개
- 이 티어인 이유: 다중 케이스와 출력 형식 처리가 겹침
- 핵심 관찰: 평균은 실수로 계산
- 흔한 실수: 평균을 정수 나눗셈으로 계산; 출력 형식(소수 셋째 자리, % 기호); 평균과 같은 점수는 제외
- 출처: 웹

### 2309 일곱 난쟁이 (브론즈 1) — 브루트포스 알고리즘, 정렬
- 무엇을 구하나: 아홉 난쟁이 키 중 합이 100이 되는 일곱 명을 찾아 키를 오름차순으로 출력한다.
- 지문 유형: 이야기형(동화 소재)
- 입력: 9줄, 난쟁이 키
- 제약: 키는 100 이하 자연수, 서로 다름, 답은 유일
- 시간 제한: 2초
- 의도 풀이: 전체합-100과 같은 두 명을 이중 반복문으로 찾아 제외하고 정렬 출력
- 복잡도: O(81 + 9 log 9)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 이야기형, 예제 1개
- 이 티어인 이유: 브루트포스 설계와 정렬을 조합해야 함
- 핵심 관찰: 일곱 명을 고르기보다 제외할 두 명을 찾는 것이 쉬움
- 흔한 실수: 정답을 여러 번 출력; 정렬 누락; 같은 사람을 두 번 제외
- 출처: 웹

### 2775 부녀회장이 될테야 (브론즈 1) — 수학, 구현, 다이나믹 프로그래밍
- 무엇을 구하나: a층 b호에는 아래층 1호부터 b호까지 사람 수의 합만큼 산다는 규칙으로 k층 n호의 인원을 구한다.
- 지문 유형: 실생활 규칙형 - 아파트 거주 인원
- 입력: 테스트케이스 T, 각 케이스는 k와 n
- 제약: 1 ≤ k, n ≤ 14, 0층 i호에는 i명
- 의도 풀이: 층별 누적합 DP 테이블
- 복잡도: O(k·n) 또는 전처리 후 O(1)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 규칙 설명이 길고 예제 하나
- 이 티어인 이유: 점화식을 직접 세워야 해 브론즈 1
- 핵심 관찰: 각 칸은 아래층 누적합이라 점화식 d[k][n]=d[k][n-1]+d[k-1][n]
- 흔한 실수: 0층 초기값; 층과 호 인덱스 혼동
- 출처: 웹

### 17247 택시 거리 (브론즈 1) — 수학, 기하학, 사칙연산
- 무엇을 구하나: 격자에서 1로 표시된 두 칸 사이의 맨해튼 거리를 구하는 문제로 기억한다.

- 제약: 모름
- 의도 풀이: 1의 두 좌표를 찾아 /dx/+/dy/
- 복잡도: O(NM)
- 비틀기: 모름
- 막히는 쉬운 풀이: 모름
- 지문 특징: 모름
- 이 티어인 이유: 모름
- 출처: 기억

### 4796 캠핑 (브론즈 1) — 수학, 그리디 알고리즘
- 무엇을 구하나: 연속 P일 중 L일만 쓸 수 있는 캠핑장을 V일 휴가 동안 최대 며칠 쓸 수 있는지 구한다. 여러 케이스를 0 0 0까지 처리한다.
- 지문 유형: 이야기형 - 캠핑장 이용
- 입력: L P V 한 줄씩, 0 0 0이면 종료
- 제약: 모름(L<P<V 범위의 정수)
- 의도 풀이: L*(V//P) + min(L, V%P)
- 복잡도: O(케이스 수)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 짧은 이야기, 예제 한 개, 출력 형식 'Case i: 답'
- 이 티어인 이유: 공식은 단순하나 부분 주기 처리를 놓치기 쉬워 브론즈 1
