# 실버 문제 특징

> solved.ac 메타데이터(2026-10-13, 실버 5,298문제)와 대표 문제 42개 분석. 대표 문제는 인터넷 검색으로 확인하고, 찾지 못한 것은 기억으로 채웠다(출처 칸). 지문 원문은 담지 않는다.

## 요약: 실버로 만들 때

- **풀이**: 표준 기법 하나. 문제당 태그 2.4~2.8개. 실버 5에서 1로 갈수록 구현 비중이 52%→22%로 줄고, 그래프·그리디·브루트포스가 늘어난다. 대표 문제 42개 중 "비튼 점"이 있는 것은 7개로, 대부분 기법을 그대로 쓴다.
- **세부 티어**
  - 실버 5: 기법을 그대로 한 번 (정렬, 집합·이분 탐색으로 존재 확인, 조합 nCr, 작은 범위 완전 탐색, 연결 요소 세기). 관찰 1개.
  - 실버 3: 기본 DP(1로 만들기, 퇴사), 1차원 누적 합, 그래프 도달 가능 정점 세기, 답을 이분 탐색하는 매개 변수 탐색 입문, 최저가 유지 그리디(주유소). 관찰 1~2개.
  - 실버 1: 기법 하나를 한 번 응용 (격자 BFS 최단 거리, 2차원 상태 DP(RGB거리: 이전 색에 따라), 이분 탐색 + 그리디 판정, 분할 정복 거듭제곱, 2차원 누적 합, 나머지 성질 관찰(카잉 달력)). 관찰 2~3개.
- **DP**: 실버 5는 조합(파스칼 삼각형), 실버 3은 1차원 점화식(dp[i] = 앞 몇 칸의 최소·최대 + 비용), 실버 1은 상태가 하나 더 붙은 점화식(dp[i][색]). 점화식은 지문에 없고 학생이 세워야 한다.
- **제약과 시간 제한**: 여기부터 시간 제한이 쉬운 풀이를 막는다. N이 10⁵~10⁶이면 O(N²)이 막힌다 (숫자 카드 N, M ≤ 5×10⁵, 1로 만들기 N ≤ 10⁶, 구간 합 N, M ≤ 10⁵). 반대로 완전 탐색이 의도면 N이 아주 작다 (퇴사 N ≤ 15, 연산자 끼워넣기 N ≤ 11).
- **지문**: 이야기형이 조금 더 많다 (일상 소재: 회사, 주유소, 프린터, 선거). 규칙을 여러 문장으로 정확히 정의하고, 경계(같은 순위 없음, i ≤ j 등)를 명시한다. 예제 2~3개.
- **흔한 실수 (TC에 넣을 것)**: 합·곱의 32비트 오버플로(주유소 값 ≤ 10⁹), 1-index/0-index, 빈 결과, 이분 탐색 경계(답이 없을 때 -1).
- **만들 때**: 기법 하나를 정하고, 학생이 "이건 누적 합/BFS/DP다"를 알아채는 단계가 관찰 1개가 되게 한다. 그 기법을 쓰지 않는 쉬운 풀이가 시간 초과가 나도록 N을 잡는다. 기법 두 개를 엮으면 골드로 올라간다.

## 문제별 특징

### 2178 미로 탐색 (실버 1) — 그래프 이론, 그래프 탐색, 너비 우선 탐색, 격자 그래프
- 무엇을 구하나: 0/1 미로에서 (1,1)에서 (N,M)까지 지나는 최소 칸 수를 구한다.
- 지문 유형: 이야기형(미로)
- 입력: N, M과 N개의 0/1 문자열 행
- 제약: 2 ≤ N, M ≤ 100
- 의도 풀이: 격자 BFS로 최단 거리
- 복잡도: O(N×M)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: DFS 전수 탐색은 비효율
- 지문 특징: 짧고 예제 4개
- 이 티어인 이유: BFS 최단 거리 기본형
- 핵심 관찰: 가중치가 같으므로 BFS가 최단 경로; 시작, 도착 칸도 센다
- 흔한 실수: 공백 없이 붙어 있는 입력 파싱; 시작 칸 포함 여부; 범위 검사
- 출처: 웹

### 6236 용돈 관리 (실버 1) — 이분 탐색, 매개 변수 탐색
- 무엇을 구하나: N일간 지출이 정해져 있고 정확히 M번 인출할 때, 인출 금액 K의 최솟값을 구한다.

### 5525 IOIOI (실버 1) — 문자열
- 무엇을 구하나: I와 O로 된 문자열 S 안에 I와 O가 교대로 N번 반복되는 패턴 P_N이 몇 번 나타나는지 센다.
- 지문 유형: 추상형
- 입력: N, 길이 M, 문자열 S
- 제약: N, M ≤ 1,000,000 (정확한 값은 기억 기반)
- 시간 제한: 1초
- 의도 풀이: IOI 연속 반복 길이를 한 번 훑으며 세어 N 이상이면 길이에서 N을 뺀 만큼 더하기
- 복잡도: O(M)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 각 위치에서 2N+1 길이를 비교하는 O(MN) 풀이는 부분점수만
- 지문 특징: 패턴 정의를 수식으로 설명, 부분 점수 서브태스크가 있음
- 이 티어인 이유: 선형 스캔 발상이 필요
- 핵심 관찰: 연속 IOI 블록이 길면 P_N이 여러 번 겹쳐 나옴
- 흔한 실수: 겹치는 등장 처리, 제대로 O(M)으로 줄이기; 겹치는 패턴 중복 계산; 초과 시간
- 출처: 웹

- 흔한 실수: N+1일을 넘기는 상담 처리, 인덱스 경계; 종료 조건 인덱스; 기간이 남은 일수를 넘는 경우

### 2751 수 정렬하기 2 (실버 5) — 정렬
- 무엇을 구하나: N개의 수를 오름차순으로 정렬해 출력한다.
- 지문 유형: 추상형
- 입력: N, 수 N개
- 제약: N ≤ 1,000,000, /값/ ≤ 1,000,000, 중복 없음
- 시간 제한: 2초
- 의도 풀이: O(N log N) 정렬(내장 정렬 또는 병합 정렬)
- 복잡도: O(N log N)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 버블/삽입 정렬(O(N^2))
- 지문 특징: 매우 짧은 지문
- 이 티어인 이유: 정렬 호출 한 번이면 해결
- 핵심 관찰: N이 커서 O(N^2) 정렬 불가
- 흔한 실수: 빠른 입출력 필요; 입출력 속도; 최악 O(N^2) 퀵정렬 구현
- 출처: 웹

### 2941 크로아티아 알파벳 (실버 5) — 구현, 문자열
- 무엇을 구하나: 몇 가지 특수 표기(c=, dz= 등)를 한 글자로 세어 단어가 몇 글자인지 구한다.
- 지문 유형: 실생활 규칙형: 크로아티아 문자 표기
- 입력: 단어 하나
- 제약: 길이 ≤ 100
- 시간 제한: 1초
- 의도 풀이: 패턴을 한 글자로 치환하거나 순차 스캔하며 센 뒤 길이 계산
- 복잡도: O(L)
- 비틀기: 없음(기법 그대로)
- 막히는 쉬운 풀이: 없음
- 지문 특징: 표로 알파벳 목록 제시, 예제 여러 개
- 이 티어인 이유: 구현 위주지만 처리 순서 주의
- 핵심 관찰: dz=를 d-/z=보다 먼저 처리
- 흔한 실수: dz=가 d와 z=로 쪼개지는 경우, ddz=z= 같은 연속 처리; 치환 순서; lj, nj가 하나로 취급되는 점
- 출처: 웹
