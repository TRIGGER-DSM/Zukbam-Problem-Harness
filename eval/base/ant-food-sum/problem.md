# 개미의 먹이 구간

## 문제

일직선 길 위에 칸이 $N$개 있고, 왼쪽부터 1번, 2번, …, $N$번 칸이다. $i$번 칸에는 먹이 점수 $a_i$가 적혀 있다. 점수는 음수일 수도 있다. 음수는 그 칸에 독이 있다는 뜻이다.

개미가 $Q$번 산책을 한다. 각 산책은 $l$번 칸에서 시작해 $r$번 칸까지 오른쪽으로 걸어가며, 지나는 모든 칸($l$번 칸과 $r$번 칸 포함)의 점수를 얻는다.

각 산책에서 개미가 얻는 점수의 합을 구하시오.

## 입력

첫째 줄에 칸의 수 $N$과 산책 횟수 $Q$가 공백을 사이에 두고 주어진다. ($1 \le N \le 200\,000$, $1 \le Q \le 200\,000$)

둘째 줄에 $a_1, a_2, \ldots, a_N$이 공백을 사이에 두고 주어진다. ($-10^9 \le a_i \le 10^9$)

다음 $Q$개의 줄 중 $j$째 줄에 $j$번째 산책의 $l$과 $r$이 공백을 사이에 두고 주어진다. ($1 \le l \le r \le N$)

입력으로 주어지는 수는 모두 정수이다.

## 출력

$Q$개의 줄에 걸쳐, $j$째 줄에 $j$번째 산책에서 얻는 점수의 합을 출력한다.

## 제한

- 시간 제한: 1초
- 메모리 제한: 256MB

## 예제 설명

예제 1에서 첫 번째 산책은 2번 칸부터 4번 칸까지이므로 $2 + (-1) + 4 = 5$이다.
