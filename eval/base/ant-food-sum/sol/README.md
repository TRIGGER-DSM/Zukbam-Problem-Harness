# 풀이 근거

## 핵심 아이디어
누적합 pre[i] = a_1 + … + a_i를 미리 구하면 구간 [l, r]의 합은 pre[r] − pre[l−1]이다.

## 왜 맞는가
pre[r] = a_1 + … + a_r, pre[l−1] = a_1 + … + a_{l−1}이므로 둘의 차는 a_l + … + a_r이다. pre[0] = 0으로 두면 l = 1도 같은 식이다.
합의 절댓값은 최대 200 000 × 10^9 = 2 × 10^14이므로 64비트 정수로 충분하다.

## 시간·공간 복잡도
O(N + Q) 시간, O(N) 공간.
