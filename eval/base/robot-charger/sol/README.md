# 풀이 근거

## 핵심 아이디어
끝나는 시각이 빠른 신청부터 보면서, 마지막으로 받아들인 신청의 끝 시각 이후(같은 시각 포함)에 시작하면 받아들인다.

## 왜 맞는가
끝 시각이 가장 빠른 신청 x를 생각하자. 어떤 최적해든 그 최적해에서 끝 시각이 가장 빠른 신청 y를 x로 바꿔도 된다. x는 y보다 늦게 끝나지 않으므로 y 다음 신청들과 겹치지 않기 때문이다. 그러면 x를 포함한 최적해가 있고, x와 겹치지 않는 신청들에 대해 같은 논리를 반복하면 된다.
끝과 시작이 같은 신청은 겹치지 않으므로 비교는 `s >= last`이다.

## 시간·공간 복잡도
정렬 O(N log N), O(N) 공간.
