# 로봇 충전기

## 문제

공장에 충전기가 하나 있다. 로봇 $N$대가 충전기 사용을 신청했다. $i$번 로봇은 시각 $s_i$에 충전을 시작해 시각 $e_i$에 끝내고 싶어 한다.

충전기는 한 번에 로봇 한 대만 충전할 수 있다. 신청을 받아들인 로봇은 시각 $s_i$부터 $e_i$까지 중간에 멈추지 않고 충전해야 한다. 어떤 로봇의 충전이 끝나는 시각과 다른 로봇의 충전이 시작하는 시각이 같아도 된다.

받아들일 수 있는 신청의 최대 개수를 구하시오.

## 입력

첫째 줄에 로봇의 수 $N$이 주어진다. ($1 \le N \le 200\,000$)

다음 $N$개의 줄 중 $i$째 줄에 $s_i$와 $e_i$가 공백을 사이에 두고 주어진다. ($0 \le s_i < e_i \le 10^9$)

입력으로 주어지는 수는 모두 정수이다.

## 출력

첫째 줄에 받아들일 수 있는 신청의 최대 개수를 출력한다.

## 제한

- 시간 제한: 1초
- 메모리 제한: 256MB

## 예제 설명

예제 1에서는 [1, 3), [3, 5), [5, 8)의 3개를 받아들일 수 있다. 끝나는 시각과 시작하는 시각이 같아도 되기 때문이다.
